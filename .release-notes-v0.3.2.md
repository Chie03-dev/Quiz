## Quiz Instructor v0.3.2

### Fixed
- Geography College exam PDF import: a multi-page exam that imported as 69
  mis-typed questions now parses as 45 questions across all 8 types (MCQ,
  True/False, Identification, Fill-in, Enumeration, Problem Solving, Matching,
  Connect) with every answer key resolved.
- True/False keys with trailing explanation text (e.g. "FALSE. Perihelion
  occurs in early January...") now resolve to a boolean instead of being left
  blank.
- Roman-numeral section headers ("V. Enumeration", "VII. Matching") and the
  "True / False" (slash) header are recognized again.
- Printed answer-box lines ("1. ____") and fragments like "6.5°C per 1,000 m"
  no longer spawn spurious questions.
- Matching sections from PDFs (line-based, no table block) are rebuilt into a
  pair table and keyed from the answer key.
- Connect question data is built with the correct Choice shape.
